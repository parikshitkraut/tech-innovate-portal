PHOTO PLACEMENT DIRECTORY
========================

To display real photographs of Dr. Pravin Kale and Dr. Sandeep Kale:

1. Copy your portrait photos into this folder:
   - For Founder Dr. Pravin Kale: save as `founder-pravin.jpg` (or .png)
   - For Co-Founder Dr. Sandeep Kale: save as `founder-sandeep.jpg` (or .png)

2. In `assets/js/config.js`, verify the file path under the `founders` array:
   image: "assets/images/founder-pravin.jpg"
   image: "assets/images/founder-sandeep.jpg"

If no photo is placed, the website automatically displays an elegant futuristic monogram avatar.
